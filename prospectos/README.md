# Prospectos

Acá el agente `prospectador-ml` (`.claude/agents/prospectador-ml.md`) guarda las listas de sellers de Mercado Libre para consultoría. Un archivo por corrida: `AAAA-MM-DD-<categoria>.md`.

Uso: pedirle a Claude Code "usá prospectador-ml para buscar 15 prospectos de <categoría>". El agente no contacta a nadie: la decisión y el envío son tuyos.
